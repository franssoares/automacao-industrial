# DCA3607 — Automação Industrial

Repositório acadêmico e técnico desenvolvido no âmbito da disciplina **DCA3607 - AUTOMAÇÃO INDUSTRIAL**, ministrada no Departamento de Engenharia de Computação e Automação (DCA) da Universidade Federal do Rio Grande do Norte (UFRN).

O repositório reúne projetos, códigos em linguagens da norma **IEC 61131-3** (com ênfase em Diagrama Ladder — LD), modelagens formais de sistemas a eventos discretos (Autômatos Finitos Determinísticos — AFD), telas de Interface Homem-Máquina (IHM) e documentações técnicas executadas e validadas no kit didático industrial **Training Box DUO TB131** (Altus).

## Plataforma Tecnológica e Kit Didático

### 1. Kit Didático: Altus Training Box DUO TB131

Os experimentos laboratoriais utilizam a maleta didática industrial **Training Box DUO TB131** da Altus Sistemas de Automação. O kit integra em um único painel portátil recursos didáticos para treinamento completo em automação discreta e contínua:

- Chaves fim de curso, botões pulsadores e seletores para geração de sinais digitais.
- Barramentos de sinalização com LEDs de alta visibilidade para saídas digitais.
- Potenciômetros e instrumentos para simulação de entradas e saídas analógicas ($0\text{--}10\,\text{V}$ / $4\text{--}20\,\text{mA}$).
- Manual técnico oficial do kit disponível no repositório: [`KitDidaticoMaletaAltus.pdf`].

- Controlador Lógico Programável (CLP): Altus Duo DU350 / DU351
- Ambiente de Programação: MasterTool IEC (CoDeSys v2.3)

## Como Clonar, Configurar e Executar

### 1. Clonagem do Repositório

```bash
git clone https://github.com/franssoares/automacao-industrial.git
cd automacao-industrial
```

### 2. Execução no MasterTool IEC (CoDeSys v2.3)

1. Inicie o software **MasterTool IEC**.
2. **Para abrir o projeto já existente:** Selecione `Arquivo` $\to$ `Abrir` e navegue até o arquivo `.pro` da atividade.
